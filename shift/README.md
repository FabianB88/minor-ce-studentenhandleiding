# SHIFT

Mobiele kennisgame bij de minor Circulaire Economie.

Per week: 24 toepassingsvragen, 6 brede Open Deur-thema’s en 3 puzzels. Ook Connectie, solo oefenen en beurtelingse duels voor twee spelers.

Website: https://fabianb88.github.io/minor-ce-studentenhandleiding/shift/

De frontend wordt met GitHub Pages gepubliceerd. Een aparte duelservice beheert gedeelde voortgang, tijd en punten; het endpoint staat in duels.js. Een willekeurige spelerssleutel blijft in de browser. Duels blijven 14 dagen beschikbaar. Offline werkt solo; voor duels is internet nodig.

De vragen zijn brongecontroleerd op de volledige e-learningblokken. Fictieve praktijksituaties zijn toepassingen van de theorie, geen letterlijke cursuscasussen. Docentbeoordeling wordt niet geclaimd.
